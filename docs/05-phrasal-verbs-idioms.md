# PHẦN A — PHRASAL VERBS

## Cách dùng: bốn loại

| Loại | Đặc điểm | Ví dụ |
|---|---|---|
| **Nội động từ** | không có tân ngữ, không tách | The plane **took off**. |
| **Ngoại động, tách được** | tân ngữ ở giữa hoặc sau; **đại từ bắt buộc ở giữa** | Turn the light **off** = Turn **it** off ✔ (turn off it ❌) |
| **Ngoại động, không tách** | tân ngữ luôn đứng sau cả cụm | look after **them** ✔ (look them after ❌) |
| **Ba thành phần** | không bao giờ tách | look forward **to** it, put up **with** him |

## Nhóm UP — hoàn tất, tăng lên, hướng lên

| Phrasal verb | Nghĩa | Ví dụ |
|---|---|---|
| give up | từ bỏ | He **gave up** smoking. |
| set up | thành lập, thiết lập | They **set up** a company. |
| bring up | nuôi dạy; nêu vấn đề | She **brought up** a good point. |
| make up | bịa ra; làm hoà; trang điểm | He **made up** an excuse. |
| pick up | nhặt lên; đón; học lỏm | I'll **pick you up** at 7. |
| put up with | chịu đựng | I can't **put up with** this noise. |
| catch up (with) | bắt kịp; hàn huyên | Let's **catch up** soon. |
| speed up | tăng tốc | We need to **speed up**. |
| wake up | thức dậy | I **wake up** at 6. |
| show up | xuất hiện | He didn't **show up**. |
| come up with | nghĩ ra | She **came up with** an idea. |
| end up | rốt cuộc lại | We **ended up** staying home. |
| take up | bắt đầu (sở thích); chiếm chỗ | I **took up** yoga. |
| look up | tra cứu | **Look up** the word. |
| grow up | lớn lên | I **grew up** in Hue. |

## Phrasal verb ↔ Động từ đơn trang trọng

Dùng **phrasal verb** khi **nói**; dùng **động từ đơn** khi **viết học thuật**.

| Phrasal verb (nói) | Động từ đơn (viết) |
|---|---|
| find out | discover, determine |
| carry out | conduct, perform |
| put off | postpone |
| call off | cancel |
| set up | establish |
| look into | investigate |
| go up / go down | increase / decrease |
| point out | indicate |
| come up with | devise, propose |
| deal with | handle, address |
| turn down | reject, decline |
| get rid of | eliminate |
| bring about | cause |
| cut down on | reduce |
| take part in | participate in |
| leave out | omit |

# PHẦN B — COLLOCATION

## MAKE / DO / TAKE / HAVE / GET

| Động từ | Đi với |
|---|---|
| **MAKE** | a decision, a mistake, progress, an effort, money, a noise, friends, a plan, an appointment, a suggestion, a difference, sure |
| **DO** | homework, the housework, the washing-up, business, research, exercise, your best, a favour, the shopping, damage |
| **TAKE** | a photo, a break, a risk, place, care of, part in, responsibility, medicine, notes, an exam, a seat, time |
| **HAVE** | breakfast/lunch/dinner, a shower, fun, a look, an idea, a problem, an effect, a rest, a conversation, an accident |
| **GET** | a job, married, lost, angry, better, in touch, rid of, ready, dressed, home, permission |

## Collocation theo danh từ (trình độ B2–C1)

| Danh từ | Đi với |
|---|---|
| **problem** | tackle / address / pose / solve a problem; a pressing / serious problem |
| **impact** | have a profound / lasting / adverse / significant impact on |
| **decision** | make / reach / reverse a decision; a sound / difficult decision |
| **opportunity** | seize / miss / provide / create an opportunity |
| **attention** | pay / draw / attract / require attention |
| **evidence** | compelling / conclusive / anecdotal / overwhelming evidence |
| **change** | undergo / bring about / implement a change; a radical / gradual change |
| **role** | play a crucial / pivotal / vital / major role in |
| **effort** | make an effort; a concerted / joint / considerable effort |
| **research** | conduct / carry out research; extensive / ongoing research |
| **risk** | take / pose / run / minimise a risk |
| **standard** | meet / raise / maintain / lower standards |

## Cách học phrasal verb & thành ngữ hiệu quả

1. **Học theo nhóm tiểu từ**, không theo bảng chữ cái (up, down, out, off…).
2. **Luôn học trong câu.** `put off` một mình vô nghĩa; `They put off the meeting until Friday` mới nhớ được.
3. **Mỗi ngày 5 cụm, không hơn.** 5 cụm/ngày × 30 ngày = 150 cụm — đủ dùng cho mọi tình huống.
4. **Dùng ngay trong ngày.** Viết 1 câu của riêng bạn cho mỗi cụm mới học.
5. **Phân biệt ngữ cảnh.** Ghi rõ cụm nào là khẩu ngữ (không dùng trong bài viết trang trọng).
